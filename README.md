# Bakul Air Fryer

Aplikasi telefon untuk 40 snek air fryer yang murah, sihat dan senang, daripada ayam, daging, kentang, roti putih dan telur. Ada tab ikut bahan, lukisan cara potong, pemasa, kalkulator kos sebulan dan senarai beli Instamart.

Pelan, tanda senarai beli dan harga yang diubah disimpan dalam telefon sahaja.

Bina semula selepas menukar halaman artifact Claude: salin HTML ke `src/bakul.html`, kemudian jalankan `node tools/build.js src/bakul.html`. Naikkan `CACHE` dalam `sw.js` supaya telefon dapat versi baru.

Pratonton lokal: `node tools/serve.js` (http://localhost:8141).
