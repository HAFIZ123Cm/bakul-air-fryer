# Bakul Air Fryer

Aplikasi telefon: 64 resepi murah dan cepat untuk air fryer dan dapur induksi, daripada kulit ayam, daging, kentang, roti putih dan telur. Ada kalendar untuk rancang menu, mod masak langkah demi langkah dengan pemasa, lukisan cara potong, kira kos sebulan dan senarai beli. Dua tema: Pagi dan Malam.

Rancangan kalendar, tanda senarai beli dan harga yang diubah disimpan dalam telefon sahaja.

Bina semula selepas menukar halaman artifact Claude: salin HTML ke `src/bakul.html`, kemudian jalankan `node tools/build.js src/bakul.html`. Naikkan `CACHE` dalam `sw.js` supaya telefon dapat versi baru.

Pratonton lokal: `node tools/serve.js` (http://localhost:8141).
